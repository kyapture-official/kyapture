## Fake, dead, or misleading controls found

The controls below were found by source audit and browser inspection; none was changed in this task.

1. **Dashboard global search** — `frontend/src/components/layout/DashboardLayout.jsx`: the “Search anything...” input only changes focus styling; it has no value state, search handler, or result surface.
2. **Landing header** — `frontend/src/components/landing/Navbar.jsx`: the Kyapture logo is `href="#"`; the desktop/mobile top-level **Products** item also resolves to `#` (its child anchors work as section links).
3. **Landing CTA/footer identity** — `frontend/src/components/landing/Footer.jsx`: “Get Started Free” and the footer Kyapture logo are `href="#"`.
4. **Landing social links** — `Footer.jsx`: Website, Community, Newsletter, and Email are each `href="#"`.
5. **Landing footer product links** — `Footer.jsx`: Client Gallery, Portfolio Website, Studio Manager, Digital Store, and AI Photo Editor are each `href="#"`.
6. **Landing footer resource links** — `Footer.jsx`: Blog, Help Center, Tutorials, API Docs, and Community are each `href="#"`.
7. **Landing footer company links** — `Footer.jsx`: About Us, Careers, Press Kit, Partners, and Contact are each `href="#"`.
8. **Landing footer legal links** — `Footer.jsx`: Privacy Policy, Terms of Service, Cookie Policy, GDPR, and DPA are each `href="#"`.
9. **Misrouted landing navigation** — `Navbar.jsx`: “Pricing” anchors to `#stats`, rather than a pricing/billing surface.
10. **Demo-only feature cards** — `frontend/src/components/landing/Features.jsx`: Portfolio Website, Studio Manager, and AI Photo Editor cards only swap local decorative previews. They do not open or operate the advertised products; the footer also advertises the unimplemented Digital Store.

The landing gallery category filter and testimonial carousel are not included above: both perform their stated local UI interactions. The current list comprises 29 dead controls (the dashboard search plus 28 `#` anchors) and the misrouted/demo-only surfaces noted separately.
